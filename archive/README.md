# Archive

Files moved out of the active pipeline. Nothing here was deleted — `git log
--follow <path>` shows full history for any of these. See the main
[README](../README.md) for the active pipeline.

| File | Why archived |
|---|---|
| `s9models.py` | **Superseded, and stale.** Read the old buggy `data/inplay_snapshots.csv` (fixed in commit `d3d7469`) — its outputs (`S9_metrics_summary.csv`, coefficient/importance plots, calibration plots below) reflect the `target_runs` `max()`-vs-`sum()` bug, not real model performance. Superseded by the checkpoint pipeline (`build_checkpoint_datasets.py` + `validate_temporal.py`). |
| `s10improveacc.py` | **Superseded, and stale.** Also reads the old buggy `data/inplay_snapshots.csv`. This is the script that produced `S10_model_comparison.csv` — the source of the old README's "AUC 0.61 / Brier 0.24" headline, which was from a different, weaker match-level model than the checkpoint pipeline, computed on incorrect data. Superseded by the checkpoint pipeline. |
| `S9_logit_calibration.png`, `S9_logit_coefficients.png`, `S9_rf_calibration.png`, `S9_rf_feature_importance.png`, `S9_xgb_calibration.png`, `S9_xgb_feature_importance.png` | **Stale.** Generated by `s9models.py` from the old buggy snapshot data. Not representative of current model performance. |
| `S10_logit_calibration.png`, `S10_rf_calibration.png`, `S10_gb_calibration.png` | **Stale.** Generated by `s10improveacc.py` from the old buggy snapshot data. |
